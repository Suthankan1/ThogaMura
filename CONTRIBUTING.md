# Contributing as a five-member group

1. Read `AGENTS.md`, `docs/TEAM_WORKLOADS.md` and the relevant contract.
2. Assign an owner and choose a narrow backlog item.
3. Branch from main (example `feat/m3-nio-selector`), write the behavior/test, make one small commit.
4. Open PR with `.github/pull_request_template.md`. Don't merge protocol or schema changes without team review.
5. Rerun Java and/or frontend checks and attach actual output. Have another member read the JDK networking code.
6. Update `docs/handoffs/TEMPLATE.md` copy to describe the next integration step.

Commit style examples: `feat(tcp): frame json command messages`; `test(inventory): verify concurrent reservation`; `docs: freeze network protocol v1`.

## Academic integrity

AI assistance is permitted only to the extent your course policy allows. Each student must be able to explain, alter, test and demonstrate the code they claim as their individual contribution. Do not fabricate results or submit unexplained generated features.

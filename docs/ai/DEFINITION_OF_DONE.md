# Definition of done for a small slice

- [ ] Owned by a named member; matches a specific lecture concept where relevant.
- [ ] Behavior, request/response and failure path documented.
- [ ] No undocumented change to shared protocol, DB schema or HTTP API.
- [ ] Test proves behavior (unit, integration or LAN as appropriate).
- [ ] Demonstration uses the **actual** Java networking API and two processes/devices if required.
- [ ] Timeouts, bounds, cleanup, retries and logs reviewed.
- [ ] User-visible loading/error state when the slice touches UI.
- [ ] No credentials, build artifacts or real customer data added.
- [ ] Clean build command and observed result recorded; unrun tests disclosed.
- [ ] PR and handoff note are small and understandable to another group member.

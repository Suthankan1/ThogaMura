Try the ThogaMura demo

  1. Open Products and request available stock.
  2. Submit a request, then track it in Requests.
  3. Open Warehouse queue, mark it picked, then dispatch it.
  4. Check Suppliers for out-of-stock ITEM-008.
  5. In Activity & network, enable “Drop next response”, then submit a request and retry safely with the same ID.

Everything runs in this file with local demo data. No network packets, database, or backend services are involved.
